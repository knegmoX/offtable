## A. 安装与启动（主机 App）
- [ ] APK 安装后桌面图标、名称正常；首次启动无任何权限弹窗
- [ ] 冷启动到可点击：`adb shell am start -W app.offtable.games/.MainActivity`，记录 TotalTime（目标：中端 ≤1.0s，低端 ≤2.0s）
- [ ] 人机「困难」连续下 20 手，记录 AI 最长思考时间（目标 p95 ≤1.5s，低端机）
- [ ] 待机看棋盘 60 秒：手机不发热；（可选）`adb shell top -n 1 | grep offtable` CPU ≈ 0

## B. 局域网联机：三种网络 × 每种 20 次
每次：主机「面对面联机 → 开房间」，访客用**系统相机**扫码，在浏览器里进入并完成 1 局（或至少 5 手）。

| 场景 | 访客浏览器 | 成功次数 / 20 | 失败现象 |
|---|---|---|---|
| 1. 同一 Wi-Fi（家用路由） | Chrome / Safari / 微信内置 | | |
| 2. 安卓主机开系统热点，访客连热点，**访客移动数据开** | | | |
| 2b. 同上，**访客移动数据关** | | | |
| 3. iPhone 主机开个人热点，访客连热点 | | | |
| 4. 公共 / 访客 Wi-Fi（可能有 AP 隔离，预期失败 → 记录提示是否清楚） | | | |

门槛：场景 1–3 成功率 ≥95%（否决线 <80%）。

## C. 稳定性
- [ ] 访客锁屏 60 秒后解锁：3 秒内恢复棋盘，座位不变
- [ ] 访客浏览器刷新：座位与棋局恢复
- [ ] 主机切到后台 10 秒再回来：访客看到「房主暂时离开」，回来后继续
- [ ] 8 台设备（或 8 个浏览器标签分布在 2–3 台手机）在线 30 分钟：无成批掉线
- [ ] 主机与访客往返延迟：落子到对方出现 ≤150ms（目测无明显延迟即可，可用录屏逐帧量）
